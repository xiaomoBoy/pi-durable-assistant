Pi Durable Edge

构建在 Cloudflare 上的持久化 Pi Agent。支持 faux 免费测试，以及 OpenAI / Anthropic 兼容模型 API。聊天、提醒和配置保存在 Durable Object。

访问令牌

首次使用请填写在 Cloudflare 侧设置的 ACCESS_TOKEN。
连接后可以一键验证对话、幂等提交、持久化和提醒触发（不包含模拟崩溃）。

模型设置 faux · 免费模拟

API Key 在 Worker 端使用 AES-GCM 加密保存，页面不会显示已保存的明文。更换协议或 Base URL 时必须重新填写 Key；更换 ACCESS_TOKEN 后需重新配置 API Key。仅使用你信任的 HTTPS 服务地址。模型 API 可能产生费用。

① 聊天 / 持久化任务
